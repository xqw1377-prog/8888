# v3 修订说明(第三轮,对应 EXP62D_V2_REVIEW 三处阻塞)

## 阻塞一:末仓被第二次重放清掉 → 单一事件流

v2 的盯市序列在主交易循环之后用 `closed_cum=0; pos=None` 重新构建,只回放已平仓交易,
把主循环结束时的真实末仓(空头,入场 `62959.404550`)丢了。v3 改为**同一个事件循环、
同一个持仓状态**直接产出交易、逐根盯市、期末快照;费用时点明确(入场逆向 0.05% 含于
成交价/入场根,平仓双边 0.05%×2 于退出根)。

复现复核数字:末仓毛浮亏 **−9.5709**;含期末持仓的完整合计 **−7.84 USDT**
(已平仓 +2.03 不再单独称为"实验收益")。逐根盯市最大回撤 84.18(自单一事件流)。

## 阻塞二:对账脚本不是 FIFO → 真 FIFO 批次队列

v2 的 `fifo_1m_era.py` 维护单一加权均价,属**平均成本法**(复核反例:买1@100+买1@200+卖1@150
→ 该脚本已实现 0,真 FIFO +50)。已加作废横幅保留。替代 `fifo_true.py`:
- 批次队列,反向成交先消费最早批次;自检模式复现反例(+50,期末 1@200,回合 0);
- 回合定义改为**净持仓回归零**(v2 的 23 是"反手次数",作废;真口径为 **2 个回合**);
- 1m 时代真 FIFO 已实现 **+29.43**(平均成本口径 +4.53 作废)。

## 阻塞三:缺损订单使期末数量不可认定 → 未知保留 + 区间表达

`fills_raw_v3.json` 导出全部 76 单原始字段(venue_* 缺失即 null,不丢弃)。
FILLED 但均价/量缺失的两单(ADD_222375 LONG 0.0553、EXIT_223186 SHORT 0.1661)
不参与配对、列入缺失报告;期末持仓表达为已知净量 0.3116 + 未知区间
**[0.1455, 0.3669]**。钱包对账维持**未闭合**。
