## 规则规格

唯一入口 `cts.strategy.t1.decide_exit(position, candles, mark_price, params)`:

1. **模式**由参数 `exit_mode` 声明,且已纳入参数绑定哈希:
   - `fixed`:只用已持久化的初始止损与固定止盈;**不计算、不比较移动止损**——
     彻底消除"跟踪位高于止盈时,STOP 决策被旧存储止损否决、TP 又被跟踪位遮蔽"的屏蔽区。
   - `trail`:更新 extreme 与跟踪止损(只收不利方向),通道退出(TREND)仅在此模式评估。
2. **同一标记价上的优先级**:止损先于止盈(保守);两边界分居价格两侧时一笔报价只会碰到一边。
3. **降级语义**:K 线不可用时,内核退化为对**已持久化止损/止盈**的屏障判断——与固定模式同一条
   规则;因此运行路径与降级路径对同一标记价的决策一致(由测试锁定)。
4. **证据哈希**:每个触发携带 `evidence_id`(决策事实 + 模式 + 来源的 sha256)。**来源
   (运行/降级)按设计进入哈希**:决策一致时,运行证据与降级证据的 id 必须不同——provenance
   可区分是特性,不是不一致。
5. **部署语义不变**:演示配置 `T1-DEMO-15M` 固定 `exit_mode=fixed`(8×ATR 止损、4×ATR
   止盈、TREND 关闭、不持久化跟踪位);回放/研究用 `trail`(跟踪+TREND+TP)。模式切换
   改变策略行为,必须走参数验证流程,不得直接改运行版。

## 三处消费同一内核

| 路径 | 调用 | 语义 |
|---|---|---|
| 运行(正常) | `demo_trader.step` → `decide_exit(pos, bars, mark)` | 按模式决策;fixed 不写回跟踪位 |
| 运行(降级) | K 线失败分支 → `decide_exit(pos, None, mark)` | 屏障判断,读已持久化边界 |
| 回放 | `replay.next_mark_exit`(逐标记)与收盘 `decide_exit(pos, hist, mark)` | 事件顺序扫描 + 收盘评估 |

## 验证(本轮补全;此前 4 项 + 本轮 5 项)

- 标记价扫描等价(fixed):运行 vs 降级,同一价位同 reason/同比较止损,仅 provenance 不同;
- 跟踪模式:回放逐标记扫描 ≡ 内核降级分支(读同一持久化跟踪位);
- TREND 模式门:fixed 在通道破位下不触发;trail 触发并带 trend_level;
- 证据哈希:同输入同 id,不同标记价不同 id;运行/降级 provenance 可区分;
- 交易器级等价:同一持仓与标记价,正常路径与降级路径提交同 side/qty/kind 的退出单;
- 既有回归:固定模式反例(TP 不被跟踪位遮蔽,多空双向)、穿档触发、重启保护价持久化、
  跟踪模式止损提交,全部保持通过。
